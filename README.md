# Noticias desde El Nilo · Gustave Flaubert

Aplicación web desarrollada con React + Vite que reproduce una experiencia de lectura tipo libro físico, con páginas dobles, animaciones de cambio de hoja, notas interactivas y múltiples temas visuales.

## Características

- Navegación por spreads (dobles páginas)
- Animación de volteo de página
- Menú lateral (TOC)
- Panel de notas
- Temas visuales (sepia, claro, oscuro)

## Tecnologías

- React
- Vite
- CSS

## Requisitos

- Node.js (recomendado: v18 o superior)
- npm (viene con Node)

## Instrucciones de instalación

1. Clonar el repositorio:
  ```bash
  git clone <https://github.com/Arqueholica/cartas_nilo.git>
  ```
3. Instalar dependencias:
  ```bash
  npm install
  ```
5. Ejecutar el servidor de desarrollo:
  ```bash
npm run dev
  ```
6. Abrir el navegador:
```
http://localhost:5173
```
